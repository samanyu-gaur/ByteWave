# Physics Learning Platform – Design Tokens

Use these values when creating **Color styles** and **Text styles** in Figma (Foundation page). Audience: high school students; tone: clear, friendly, built around a skill map and obvious next steps.

## Colors

| Style name | Hex | Usage |
|------------|-----|--------|
| **Primary/Text** | `#1A1A2E` | Headlines, body text |
| **Primary/Text Muted** | `#5C5C6E` | Secondary text, hints |
| **Primary/Background** | `#F8F9FC` | Screen background |
| **Primary/Background Secondary** | `#FFFFFF` | Cards, panels |
| **Accent/Main** | `#6366F1` | CTAs, primary actions, links |
| **Accent/Hover** | `#4F46E5` | Pressed/hover accent |
| **Accent/Success** | `#10B981` | Mastered, correct, success states |
| **Accent/Warning** | `#F59E0B` | In progress, review |
| **Accent/Neutral** | `#94A3B8` | Not started, inactive |
| **Skill/Not started** | `#94A3B8` | Skill node – not started |
| **Skill/In progress** | `#F59E0B` | Skill node – in progress |

## Typography (Text styles)

- **Headline 1**: DM Sans or Inter, 24px, Bold (700), line height 32px  
- **Headline 2**: DM Sans or Inter, 20px, Semibold (600), line height 28px  
- **Headline 3**: DM Sans or Inter, 18px, Semibold (600), line height 24px  
- **Body**: Inter, 16px, Regular (400), line height 24px  
- **Body Small**: Inter, 14px, Regular, line height 20px  
- **Caption**: Inter, 12px, Regular, line height 16px  
- **Label**: Inter, 12px, Semibold (600), letter spacing 0.5px  
- **Button**: Inter, 16px, Semibold (600), line height 24px  
- **Score/Number**: Inter, 20px, Bold (700), for mastery % and match %  

*Use **Inter** if DM Sans is not available; add via Figma → Resources → Add font (Google Fonts).*

## Spacing (8pt grid)

- **Grid unit**: 8px  
- **Screen padding (horizontal)**: 24px (16px for compact)  
- **Vertical padding**: 16px (12px compact)  
- **Gap small**: 8px | **Gap medium**: 12px | **Gap large**: 16px | **Gap section**: 24px  

## Layout

- **Frame (mobile)**: 390 × 844 pt (iPhone 14 Pro portrait)  
- **Frame (tablet/desktop)**: 768 × 1024 or 1440 × 900 for dashboard  
- **Safe area top**: 59pt | **Safe area bottom**: 34pt  
- **Top bar height**: 56pt | **Bottom nav** (if used): 64pt  

## Radii

- **Chip / Skill node**: 12px  
- **Card**: 12px  
- **Button**: 10px  
- **Input**: 10px  

## Shadows (optional)

- **Card**: 0 2px 8px rgba(0,0,0,0.06)  
- **Card hover**: 0 4px 16px rgba(0,0,0,0.08)
